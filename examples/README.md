# ChaseTag policy development

Use the [MyoSuite 3.1 ChaseTag Colab](https://colab.research.google.com/github/MyoHub/myosuite/blob/dev/tutorials/5.6_ChaseTag_MyoChallenge.ipynb) as the source for training, the current checkpoint, ONNX export, and local play. It maintains these pieces together.

This repository provides submission instructions: [ONNX quickstart](../tutorials/NEWBIE_QUICKSTART.md), [ONNX submission contract](../tutorials/SUBMISSION_DEPENDENCIES.md), and [submission CLI](../README.md#submission-format). Use [`../scripts/smoke_test_onnx.py`](../scripts/smoke_test_onnx.py) to check an exported model against a real ChaseTag observation.
